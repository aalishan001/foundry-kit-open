# Pack: software engineering

Software engineers and engineering managers, India first, with remote and abroad roles.

| Family | Selected by default |
|---|---|
| Backend engineering | yes |
| Full-stack engineering | yes |
| Frontend, mobile, platform/DevOps/SRE, data, ML/AI, security, engineering management, QA/SDET | no: chosen in `/start` |

The level ladder runs from intern (1) to fellow or SVP (10). Company-specific titles (Lead, Architect, Software
Engineer III, Specialist) are left off on purpose: the engine reports them as unclear and uses years required instead.
At big tech, product, fintech and SaaS companies, a title that looks lower is reported as unclear, not excluded,
because their ladders differ.

`radar.json` lists well-known employers of software engineers in India, each with its careers portal, how it is read
(automatic or paste-in), a live-check result and a sourced ownership record. Add your own with `/radar add`.

See `packs/README.md` for how packs work and how to write one for another field.
